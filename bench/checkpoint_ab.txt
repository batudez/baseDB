A/B test of the checkpoint storm fix (docs/ARCHITECTURE.md §9.6)

old = maybeCheckpoint before the fix (every commit past CheckpointBytes runs Checkpoint)
new = one automatic checkpoint at a time, size re-checked under the exclusive lock
Both binaries built from the same tree, run alternately in one session.

Embedded: bench/compare -dbs basedb -workloads update,writers -writers 1,8,32,64 -runs 2
  columns: store, threads, ops/s, avg, p50, p99, on disk
  first row = update workload (1 thread), then writers 1, 8, 32, 64
TCP:      cmd/basedb-bench -clients 16,32,64 -group-commit on
  columns: group commit, clients, ops, ops/s, p50, p99, fsyncs, writes/fsync
